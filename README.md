# Fullstack-Concepts-Explained

A growing collection of questions and answers covering JavaScript, React and Node.js. Each entry explains the *why*, not just the *what*, with short code examples you can run yourself.

## About

I created this repo to deepen my understanding of the full stack and to keep important concepts in one place. Every answer is written in my own words and backed by small, runnable examples.

**Who is it for?** Anyone learning JavaScript, React or Node.js, or brushing up on the fundamentals, from beginners to experienced developers.

## Sample Topics

**JavaScript**
- `compose` and higher-order functions
- `reduce` and its callback arguments
- `prototype` on constructors vs instances
- Object iteration and `for...in`
- Polyfill for `Object.create()`
- Throttling, event listeners with closures, prototypal inheritance (planned)

**React** and **Node.js** sections are being added.

## Format of Each Entry

Every question follows the same structure so it's easy to scan:

1. **Question**: the concept in one line
2. **Answer**: a short, plain-language explanation
3. **Code example**: a small snippet you can run
4. **Key points**: the details worth remembering

## How to Use

1. Pick a section from the table above.
2. Read the question and try answering it yourself first.
3. Check the answer, then run the code in your browser console or Node.
